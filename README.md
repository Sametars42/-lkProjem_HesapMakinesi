# -lkProjem_HesapMakinesi
C# programlama dili kullanılarak konsol (CMD) ortamında geliştirilen bu proje; dört işlem, üslü sayı, faktöriyel, mod alma ve geometrik hesaplamaları (dikdörtgen alan/çevre) kullanıcı dostu bir menü altında sunan fonksiyonel bir hesap makinesi otomasyonudur.

Temel Aritmetik İşlemler: Toplama, çıkarma, çarpma ve bölme işlemlerinin dinamik girdi yönetimi ile yapılması.
İleri Düzey Matematiksel Fonksiyonlar: Üslü sayı hesaplama, faktöriyel bulma ve mod alma algoritmaları.
Geometrik Hesaplamalar: Kullanıcıdan alınan kenar ölçüleriyle dikdörtgenin alan ve çevre hesaplamalarının otomatik yapılması.
Kapsamlı Menü Yapısı: Kullanıcının dilediği matematiksel işlemi kolayca seçebildiği ve çıkış yapabildiği (x) akıcı konsol arayüzü.

Kullanılan Teknolojiler
Programlama Dili: C# (.NET Core / .NET Framework)
Çalışma Ortamı: Konsol / Komut Satırı (CMD)
Yazılım Prensipleri: switch-case kontrol yapıları, döngüler ve fonksiyonel matematiksel işlemler.
